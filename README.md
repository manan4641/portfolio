# abdulmanan.dev

Portfolio and services site for Abdul Manan. Built from the 2026 design handoff
(`AM-Portfolio/design_handoff_portfolio_site`).

## Stack

- Next.js 14 (App Router, static generation), React 18, TypeScript
- Plain CSS design system in `src/app/globals.css` (values copied 1:1 from the design)
- Fonts via `next/font`: Bricolage Grotesque (Google), Geist and Geist Mono (`geist` package)
- three.js for the hero scene, loaded client-side after first paint
- Anthropic API (`@anthropic-ai/sdk`) for the "Ask AI" widget
- Vercel Analytics and Speed Insights

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Environment variables (Vercel → Project → Settings → Environment Variables)

| Name | Needed for |
|---|---|
| `ANTHROPIC_API_KEY` | Ask AI widget. The button is hidden until this or `LLM_RELAY_API_KEY` is set (rebuild after adding it). |
| `LLM_RELAY_API_KEY` | Ask AI through api.llmsrelay.com instead. Used only when `ANTHROPIC_API_KEY` is not set. |
| `LLM_RELAY_BASE_URL` | Optional. Relay address, default `https://api.llmsrelay.com` (no `/v1`). |
| `LLM_RELAY_MODEL` | Optional. Model ID on the relay, default `claude-opus-5-5`. |
| `NEXT_PUBLIC_GA_ID` | Google Analytics 4 (optional). Not loaded when unset. |

## Where things live

| Path | What |
|---|---|
| `src/data/site.ts` | All content: projects, roles, services, testimonials, awards, skills |
| `src/data/posts.ts` | Blog posts (summaries and article HTML) |
| `src/data/services.ts` | Services page sections |
| `src/lib/seo.ts` | Titles, descriptions, JSON-LD, shared page metadata |
| `src/lib/ai.ts` | Ask AI system prompt (built from `site.ts`) |
| `public/projects/<slug>.webp` | Project screenshots, 1280×800 |
| `public/og.png` | Default social share image, 1200×630 |

To add a project: append it to `RAW_PROJECTS` in `src/data/site.ts` (add `1` as the last
item to feature it on Home) and add `public/projects/<slug>.webp` at 1280×800.

## Routes and URL preservation

| URL | Status |
|---|---|
| `/` | Home |
| `/services` | Services |
| `/portfolio`, `/portfolio/[slug]` | All Projects and project pages (opens as a modal when clicked inside the site) |
| `/blog`, `/blog/[slug]` | All Articles and articles (the five original article URLs are unchanged) |
| `/products` | WebP plugin download (restyled; no design existed for it) |
| `/about`, `/awards`, `/contact` | 301 → `/#about`, `/#awards`, `/#contact` |
| `/work`, `/work/[slug]` | 308 → `/portfolio` (existing redirect kept) |
| `/projects` | 301 → `/portfolio` |

`sitemap.xml` and `robots.txt` are generated by `src/app/sitemap.ts` and `src/app/robots.ts`.
